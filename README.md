# OUV.INT. Clínica

**Ouvir com Intersubjetividade**

Espaço oficial de distribuição das versões Android do OUV.INT. Clínica, aplicativo de apoio à organização da atividade de profissionais de saúde mental.

## Download para Android

**Status: primeira versão de testes em preparação.** Ainda não há APK publicado ou validado para instalação.

Quando uma versão estiver disponível, consulte a página oficial de versões:

[Ver versões e baixar APK](https://github.com/alo-araujo/ouvint-clinica-downloads/releases)

Não utilize links não verificados ou arquivos distribuídos por terceiros.

## Finalidade

O aplicativo é projetado como ferramenta auxiliar de organização profissional. Não substitui prontuários regulamentares, avaliação clínica, supervisão, deveres éticos ou obrigações legais de cada profissional.

## Privacidade e testes

- Durante a fase de demonstração, utilize **somente dados fictícios**.
- Não insira informações de pacientes reais até que armazenamento, segurança, fluxos de dados e documentação de privacidade sejam testados e aprovados.
- O código-fonte do aplicativo não é distribuído neste repositório; apenas materiais públicos e futuras versões de instalação.
- A publicação de um APK não implica validação clínica, certificação ou aprovação por conselho profissional.

## Instalação (quando houver APK)

1. Acesse a página **Releases** acima pelo Android.
2. Abra a versão de teste indicada e baixe o arquivo `.apk` disponibilizado nos **Assets**.
3. Confirme a origem do arquivo e siga as instruções de instalação do Android.
4. Desative a permissão para instalar aplicativos desconhecidos depois da instalação, se tiver sido habilitada.

**Compatibilidade:** será informada após os testes do primeiro pacote.

## Suporte e atualizações

Acompanhe novas versões neste repositório. Para reportar problemas sem dados pessoais ou clínicos, utilize a seção [Issues](https://github.com/alo-araujo/ouvint-clinica-downloads/issues), se habilitada.
